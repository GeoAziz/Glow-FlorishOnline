# Glow & Flourish - A Next.js E-commerce Store

This is a modern, feature-rich e-commerce starter application built with Next.js, Firebase, and Google's Genkit for AI-powered features. It was prototyped and built in Firebase Studio.

## Project Status: Complete

The application is fully featured and ready for use. Key functionalities include:

- **Full User Authentication:** Secure user sign-up, login, and session management with Firebase Auth.
- **Role-Based Access Control:** Distinct dashboards and permissions for Users, Moderators, and Admins.
- **Complete E-commerce Flow:** Browse products, add to cart, manage wishlists, and complete orders via a full checkout process.
- **Admin & Moderator Dashboards:** Powerful back-office tools for managing products, users, orders, and moderating user-submitted reviews.
- **AI-Powered Features:**
  - **Skincare Routine Advisor:** An interactive questionnaire that suggests a personalized routine of products.
  - **Admin Product Description Generator:** An AI tool to help admins write compelling product copy.
- **Fully Configured & Deployable:** All environment variables and configurations are documented for successful deployment on Vercel.
